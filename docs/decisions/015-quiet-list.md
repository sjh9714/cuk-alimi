# ADR 015. 홈은 조용한 목록이고 관심 밖의 일은 접는다

2026-11-14

**현재 상태 (2026-11-16).** 목록과 관심 밖 접기는 그대로다. "남은 것"의 첫 줄(형광펜이 모든 행에 칠해짐)은 ADR 016이 풀었다. 형광펜은 날짜를 읽은 자리로 옮겼고, 프로필과 어긋난 일은 "다른 대상"으로 접는다.

## 배경

2026-11-14에 서비스를 다른 공지 앱(쿠링, 전대알림)과 일정 도구(Things, 투두메이트, 자소설닷컴 채용달력)에 나란히 놓고 평가했다. 마감을 뽑고 자격으로 거르는 아이디어는 비교 대상에 없는 것이었지만 화면은 믿음이 가지 않았다.

- 휴대폰 첫 화면에 할 일이 3개 보였고 그중 관심 주제는 1개였다. 위 절반은 큰 제목과 주/월 전환, 종류 고르기 다섯 개였고, 주간 판은 지난 날의 빈칸을 그대로 그렸다.
- 11월 달력의 절반 가까이가 학점교류였다. 기본 관심 주제가 아닌데도 다른 일과 같은 굵기로 칸을 채웠다. ADR 014가 형광펜은 관심 주제로 좁혔지만 판에 오르는 것은 자격만으로 정했기 때문이다.
- 제목 800, 날짜 800, 할 일 700으로 전부 굵은 남색이라 읽는 순서가 생기지 않았다.
- 설정은 입력 칸마다 단서 문단이 붙었고, 품질 페이지는 방법론 글이었다. 화면이 학생이 아니라 심사자에게 말하고 있었다.
- 주/월 전환, 푸시, 품질 페이지까지 2주 동안 더하기만 했고 뺀 것이 없었다.

시안 셋(조용한 도구, 플래너 종이, 형광펜 브랜드)을 같은 날 같은 데이터로 그려 지금 화면과 비교했고(`docs/research/2026-11-14-home-directions/`), 사용자가 조용한 도구를 골랐다.

## 결정

- **홈은 한 열 목록이다.** 날짜 제목, 요약 한 줄, 묶음(이번 주, 다음 주, 이달 안, 그 뒤), 접힌 줄 셋이다. 8칸 주간 판, 메모 칸, 앞으로의 일정 목록, 종류 고르기, 범례는 없앤다. 값은 `docs/design.md`가 기준이다.
- **관심 밖의 일은 기본으로 접는다.** ADR 014의 "구간 배치는 자격으로 정한다"를 뒤집는다. 판에 오르던 행 가운데 주제가 학생의 관심 주제 밖이면 "관심 밖 N건" 한 줄로 접는다. 로그인 전에는 기본 관심 주제 다섯 개로 거른다.
- **접지 않는 예외가 넷이다.** 학사일정 표의 항목(`must` 구간), 저장한 행, 주제가 기타이거나 없는 행, 그리고 관심 주제에 드는 행이다. 기타는 학생이 고를 수 없는 주제라 접으면 되돌릴 길이 없다. 관심 밖의 행을 저장하면 목록으로 올라온다.
- **접기는 웹이 행 단위로 한다.** 서버의 `Feed.build`와 구간은 그대로다. 저장은 줄마다 있고 학점교류 카드 한 장에 날짜가 다른 행이 여럿이라, 카드 단위인 서버 구간으로는 저장한 행만 남길 수 없다. 로그인 전 관심 주제가 빈 집합인 것은 형광펜을 칠하지 않는 근거이기도 하다. 서버 구간을 바꾸지 않으므로 정답셋 고정 파일(`gold-cards.json`)과 행 제목 점수가 그대로다.
- **아침 메일의 새 공지도 같은 규칙으로 거른다.** 화면에서 접힌 주제의 새 공지가 메일로 가던 것을 막는다(`DigestService`).
- **월 보기, 웹 푸시 화면, 공개 품질 페이지를 학생 화면에서 뺀다.** 달은 캘린더 구독이 맡고, 알림은 아침 메일과 캘린더 구독 둘로 줄인다. 정확도 수치와 방법은 README와 `docs/`로 옮긴다. 서버 코드(`/api/feed?from`, `/api/push`, `/api/quality`)는 지우지 않고 웹이 쓰지 않는 채로 둔다. 푸시는 VAPID 키가 비어 있어 꺼져 있다. 정답셋 테스트와 `quality/*.json`은 CI가 계속 지킨다.
- **구간 설명 문장은 그리지 않는다.** 서버가 구간마다 내려 주는 `note`는 응답에 남지만 화면에 쓰지 않는다. 접힌 줄에는 내역("학점교류 7 · 취업 3")만 적는다.
- **색은 둘이다.** 형광펜과 빨강. 종류별 색, 볼펜 파랑, 점 종이는 버린다.

## 고르지 않은 것

- **서버에 접힌 구간을 하나 더하기.** 메일은 구간으로 걸러서 자동으로 맞지만, 저장한 행을 남길 수 없고 `FeedTest`의 구간 단정과 `gold-cards.json` 96건 중 36건이 바뀐다.
- **관심 밖을 흐리게만 하기.** 놓칠 위험은 줄지만 학점교류가 많은 주에는 화면이 여전히 길다.
- **플래너 종이, 형광펜 브랜드 시안.** 앞의 것은 손글씨와 종이 질감이 긴 공문 이름과 부딪히고, 뒤의 것은 카드라 첫 화면에 들어가는 수가 가장 적었다.
- **행사와 책갈피 없애기.** 행사는 ADR 012가 일부러 넣었고, 저장은 메일과 캘린더의 조건이라 뺄 수 없다.

## 남은 것

- 걸러낸 뒤에는 보이는 행 대부분에 형광펜이 칠해진다(시안 6행 중 5행). 2026-11-16에 로컬 DB에서 세어 보니 시험 계정 둘 다 목록의 행 전부에 칠해졌다(11행 중 11행, 14행 중 14행. AI 대상 읽기를 끈 상태). 지금 형광펜은 목록 안에서 아무것도 구분하지 못한다. 형광펜의 뜻을 다시 정해야 한다.
- 취업·채용을 고른 학생은 홈에서 취업 공지를 보지만 새 공지 메일은 받지 못한다. 메일의 새 공지는 `must`, `mine`, `open` 구간만 보기 때문이다.
- 행 이름을 만드는 곳이 넷이다(웹, 캘린더, 푸시, 점검). 캘린더 일정의 이름이 화면과 다르다.
- 새 공지에서 행 제목이 17개 중 7개만 맞는 것은 이번 일이 아니다. 실패 10건 중 5건은 행이 아예 나오지 않은 것이고, 새 공지 25건이 쌓이면 새 셋으로 다시 잰다.
