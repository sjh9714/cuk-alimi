# 화면 디자인 계약

다음 세션과 새 화면은 이 문서의 값만 쓴다. 값을 바꾸면 여기부터 고친다. 2026-11-02에 위클리 플래너 방향으로 다시 적었다. 그 전의 흰 날짜 목록과 코발트 시안은 버렸다.

## Direction

**위클리 플래너.** 학생이 공부할 때 쓰는 불렛저널을 화면으로 옮긴다. 점 찍힌 종이, 볼펜 파랑, 형광펜, 빨간 펜이 재료다. 한 주가 한눈에 보여야 하고, 재료는 뜻이 있을 때만 쓴다. 다꾸처럼 꾸미지 않는다.

## Type

서체는 Pretendard Variable 하나. 숫자는 전부 `tabular-nums`.

| 역할 | 크기 / 굵기 / 자간 | 쓰는 곳 |
|---|---|---|
| 주 제목 | 40 / 800 / -0.025em | "11월 첫째 주" |
| 오늘 한 줄 | 19 / 700 / -0.3px | "오늘 끝나는 일 2건" |
| 날짜 숫자 | 36 / 800 / -1px | 칸 머리 |
| 다음 주 제목 | 26 / 800 / -0.5px | "다음 주" |
| 페이지 제목 | 24 / 700 / -0.5px | 홈 이외 페이지의 h1 |
| 할 일 | 16 / 700 / -0.3px | 행 제목 |
| 요일, 남은 날 | 15, 14 / 700~800 | 칸 머리 |
| 본문·입력 | 15 / 400 | 설명, 폼 |
| 메타 | 13 / 500 | 분류, 공지 이름, 시각 |

| `--ink` | `#10163F` | 할 일 글자 |
| `--body` | `#3D4366` | 본문 |
| `--mute` | `#5D6484` | 메타, 여유 있는 남은 날 |
| `--hair`, `--hair-2` | `#CFD5E6`, `#B3BBD2` | 칸 선, 입력 테두리 |

| `--alarm` | `#E5281E` | 오늘 한 줄, 오늘 숫자와 동그라미, D-2까지의 남은 날, 오류 |

분류는 글자색으로만 구분한다. 분류마다 형광펜 색을 다르게 쓰지 않는다. 다크 모드는 없다.

## Space and shape

- 칸 안 여백 16~18. 행 사이 11. 판 모서리 14, 칸 선 1px, 그림자 없음.
- 체크 18px 모서리 5. 분류 고르기 모서리 10, 안쪽 8.
- 머리글은 종이색에 밑선 하나, 위에 붙어 따라온다.

## Layout

- 본문 최대 1240px, 좌우 32. 설정, 품질, 개인정보는 한 열 680px.
- 홈은 한 주를 8칸 판으로 그린다. 월요일에 시작하는 4열 2행이고, 마지막 칸은 메모 칸이다. 이번 주 메모는 날짜 확인 중, 다음 주 메모는 그다음 일정이다.
- 읽는 순서는 주 제목, 오늘 한 줄, 분류 고르기, 이번 주 판, 다음 주 판, 접힌 구간(내 저장, 지역 장학, 특정 대상), 발 밑이다.
- 칸에는 숫자, 요일, 남은 날(오늘, 내일, D-n)이 있고 아래에 할 일 행이 쌓인다. 일이 없는 날은 숫자를 흐리게 둔다.
- 행은 체크, 할 일, 저장 책갈피 순이다. 메타 줄은 분류, 공지 이름, 시각, 내게 맞음, 자격 접기이고 간격으로만 띄운다.
- 1023px 이하는 2열, 720px 이하는 1열이고 일이 없는 날을 숨긴다. 아래 탭을 쓴다.

**할 일 이름.** 공문 제목 대신 `web/src/lib/tasks.ts`가 만든 이름을 쓴다. 한 공지의 같은 날 줄은 한 줄로 합친다("한성대, 한신대 학점교류 신청"). 라벨이 "신청기간"처럼 뜻이 없으면 공문 제목을 줄여 쓴다. 원문 제목은 링크의 `title`에 남긴다.

**행사.** 학위수여식처럼 할 일 없이 날짜만 있는 행사는 칸 아래에 "행사"와 이름, 시각을 14px 흐린 글자로 적는다. 체크, 형광펜, 남은 날을 쓰지 않고 오늘 한 줄의 건수에도 세지 않는다.

**분류.** 학생이 보는 분류는 전체, 장학, 학사, 취업이다. 학사일정 표의 항목도 학사로 묶는다. 출처 구분은 서버의 `kind`에만 남긴다.

**체크와 저장.** 체크는 "끝냈어요" 표시이고 이 브라우저에만 남는다(`localStorage`). 저장은 책갈피이고 서버에 남아 마감 알림 메일로 이어진다.

## Motion

없음. 접기와 펼치기는 즉시 바뀐다. 버튼 배경 전환만 120ms이고 `prefers-reduced-motion`에서는 끈다.

## States

- 불러오는 중: 판 자리에 `--paper-2` 면 하나.
- 오류: 머리 아래 `--alarm` 글자 한 줄과 "다시 시도".
- 비어 있음: 빈 칸은 그대로 두고 머리 한 줄이 "이번 주에 끝나는 일은 없어요"로 바뀐다.
- 끝냈어요: 체크가 채워지고 글자가 흐려지며 취소선, 형광펜이 사라진다. 오늘 한 줄의 건수가 줄어든다.
- 포커스: 2px `--pen` 바깥선.
