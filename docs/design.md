# 화면 디자인 계약

다음 세션과 새 화면은 이 문서의 값만 쓴다. 값을 바꾸면 여기부터 고친다. 2026-11-14에 "조용한 도구" 방향으로 다시 적었다(ADR 015). 그 전의 위클리 플래너(점 종이, 볼펜 파랑, 8칸 판)는 버렸다. 고른 시안은 `docs/research/2026-11-14-home-directions/`의 A 화면이다.

## Direction

**조용한 도구.** 흰 종이에 검은 글자로 적은 할 일 목록이다. 위계는 색이 아니라 굵기와 크기로 만든다. 색은 뜻이 있는 둘만 쓴다. 형광펜은 내게 맞는 일, 빨강은 이틀 안의 마감이다. 화면이 스스로를 설명하지 않는다. 설명이 필요한 것은 없애거나 접는다.

## Type

서체는 Pretendard Variable 하나. 숫자는 전부 `tabular-nums`. 굵기는 400, 500, 600, 700만 쓴다.

| 역할 | 크기 / 굵기 / 자간 | 쓰는 곳 |
|---|---|---|
| 날짜 제목 | 27 / 700 / -0.035em | 홈의 "11월 6일 금요일", 다른 페이지의 h1 |
| 요약 한 줄 | 15 / 400, 숫자만 600 | "이번 주 내 마감 1건, 다음 주 3건" |
| 묶음 이름 | 13 / 600 | 이번 주, 다음 주, 이달 안, 그 뒤 |
| 할 일 | 16.5 / 500 | 행 제목 |
| 메타 | 13 / 400 | 종류, 공지 이름, 시각 |
| 남은 날 | 13 / 600, 아래 줄 13 / 400 | "D-4"와 "화 10" |
| 접힌 줄 | 14.5 / 500, 내역 13 / 400 | "관심 밖 10건"과 "학점교류 7 · 취업 3" |
| 패널 제목 | 15 / 600 | 설정의 묶음 제목 |
| 본문·입력 | 15 / 400 | 설명, 폼 |
| 브랜드 | 14 / 600 | 머리글의 "CUK 알리미" |
| 탭 | 11 / 500, 고른 탭 600 | 아래 탭의 글자 |

## Color

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--paper`, `--sheet` | `#FFFFFF` | 바탕 |
| `--paper-2` | `#F5F6F8` | 비활성 입력, 불러오는 중 |
| `--ink` | `#17191F` | 제목, 할 일, 주요 버튼, 포커스 |
| `--pen`, `--select` | `var(--ink)` | 옛 이름. 값은 먹색과 같다 |
| `--select-2` | `#F1F2F4` | 고른 칩의 바탕 |
| `--body` | `#3C404B` | 본문 |
| `--mute` | `#6B7080` | 메타, 묶음 이름, 여유 있는 남은 날 |
| `--hair`, `--hair-2` | `#ECEEF2`, `#C3C7D0` | 선, 체크와 입력 테두리 |
| `--hl` | `#FFE94D` | 형광펜. 관심 주제이면서 자격이 되는 일의 제목 밑에만(ADR 014) |
| `--alarm`, `--alarm-2` | `#E5281E`, `#FDECEA` | D-2까지의 남은 날, 오류 |
| `--soon`, `--ok`와 그 옅은 값 | 그대로 | 검수 화면의 상태 표시에만 |

종류(장학, 학사, 취업, 학과)는 회색 글자로만 적는다. 종류별 색은 없다. 다크 모드는 없다. 회색 글자는 흰 바탕에서 명암비 4.5 이상이어야 한다.

## Space and shape

- 좌우 여백 22. 행 위 여백 13. 묶음 이름 위 26, 아래 선까지 9.
- 선은 1px `--hair`. 판, 카드, 그림자, 배경 무늬는 없다.
- 체크 22px, 모서리 7, 선 1.5px `--hair-2`. 끝내면 먹색으로 채운다.
- 접힌 줄 높이 46, 위아래 선 하나.
- 머리글은 흰 바탕에 밑선 하나, 위에 붙어 따라온다.

## Layout

- 본문은 한 열, 최대 680px. 머리글 안쪽도 같은 폭이다. 휴대폰이 기준이고 넓은 화면은 같은 열을 가운데 둔다.
- 720px 이하는 아래 탭(아이콘과 글자)을 쓴다.
- 홈의 읽는 순서는 날짜 제목, 요약 한 줄, 묶음(이번 주, 다음 주, 이달 안, 그 뒤), 접힌 줄 셋, 발 밑이다. 종류 고르기, 주/월 전환, 범례는 없다.
- 묶음은 월요일에 시작하는 주로 나눈다. 일이 없는 묶음은 그리지 않는다. "그 뒤"가 8행을 넘으면 "더 보기"로 자른다.
- 행은 체크, 할 일, 오른쪽의 남은 날과 날짜, 로그인했으면 책갈피 순이다. 할 일 제목은 두 줄까지이고 넘치면 "…"로 줄인다. 메타 줄은 종류, 공지 이름, 시각이고 간격으로만 띄운다.
- 남은 날은 "오늘", "내일", "D-n"이고 D-2까지 빨강이다. 그 아래에 "화 10"처럼 요일과 날짜를 적고, 이번 달과 다음 두 주를 넘으면 "12.3"으로 적는다.
- 내게 맞는 일은 제목 글자 아래 절반에 형광펜을 긋는다(`linear-gradient`로 52%부터 94%). 범례는 없고 칠한 이유는 제목의 `title`에 둔다.

**관심 밖 (ADR 015).** 판에 오르는 행(`must`, `mine`, `open`, `career` 구간)은 아래 중 하나면 목록에 남고, 아니면 "관심 밖"에 접힌다. 웹이 행 단위로 나눈다(`splitByInterest`).

| 남는 조건 | 이유 |
|---|---|
| `must` 구간 | 학사일정 표의 항목은 주제와 상관없이 보여 준다 |
| 저장한 행 | 관심 밖에서 책갈피를 누르면 목록으로 올라온다 |
| 주제가 기타이거나 없음 | 고를 수 없는 주제는 접지 않는다 |
| 주제가 관심 주제에 듦 | 로그인 전에는 기본 다섯 개 |

**접힌 줄.** 셋이다. "관심 밖 N건"(주제별 내역, 펼치면 체크와 책갈피가 있는 행), "다른 대상 N건"(다른 지역 장학, 특정 대상, 다른 학과를 합침), "날짜 확인 중 N건"(날짜가 그림에만 있는 공지). 목록이 비었으면 관심 밖을 펼쳐 둔다. 요약 한 줄 끝에 "관심 밖 N건"을 링크로 적어 목록이 걸러졌다는 것을 첫 화면에서 알린다.

**할 일 이름.** 공문 제목 대신 `web/src/lib/tasks.ts`가 만든 이름을 쓴다. 한 공지의 같은 날 줄은 한 줄로 합친다("한성대, 한신대 학점교류 신청"). 라벨이 "신청기간"처럼 뜻이 없으면 공문 제목을 줄여 쓴다. 할 일 라벨에 무엇의 일인지(장학금, 인턴, 계절학기, 대학원 같은 대상 이름)가 없으면 추출기(`DateItemExtractor`)가 공문 제목에서 대상 이름을 찾아 앞에 붙인다("하나장학생 트리니티 신청", "겨울 계절학기 수강신청", "바이오헬스 아카데미 1기 신청"). 붙인 이름이 36자를 넘으면 붙이지 않는다. 행 제목은 화면 기준으로 채점한다(`gold/rows.json`, 웹 `rows.test.ts`). 환불, 폐강과목 등록자 수강변경, 성적확인 및 오류정정처럼 해당하는 학생만 하는 공지 속 일정은 할 일 행에 올리지 않는다(`Feed.CONDITIONAL_LINE`). 학사일정 표의 성적확인은 그대로 올린다. 원문 제목은 링크의 `title`에 남긴다.

**시작일.** 따로 행을 만들지 않는다. 아직 시작하지 않은 일은 메타 줄에 "11월 5일부터"를 적는다.

**행사.** 학위수여식처럼 할 일 없이 날짜만 있는 행사는 같은 묶음 안에 체크 없는 회색 행으로 적는다. 남은 날을 쓰지 않고 요약 한 줄의 건수에도 세지 않는다.

**종류.** 학생이 보는 종류는 장학, 학사, 취업, 학과다. 학사일정 표의 항목도 학사로 묶는다. 출처 구분은 서버의 `kind`에만 남긴다.

**날짜 신고.** 그림에서 읽은 날짜가 섞인 행에만 메타 줄 끝에 작은 알약 "확인"(11 / 600, `--hair-2` 테두리)을 붙인다. 누르면 "공지 그림에서 읽은 날짜예요"와 글자 단추 "날짜가 달라요"가 나오고, 누르면 확인 질문 없이 신고되어 그 날짜가 내려간다. 다른 행에는 아무것도 붙이지 않는다.

**혜택.** 분류 제목은 회색 글자(13 / 600)이고 스크롤할 때 머리글 아래에 붙는다. 분류별 색과 왼쪽 막대는 없다. 오른쪽에는 마감이 있는 항목의 D-n만 적는다. 항목 전체가 접기 단추이고 오른쪽 꺾쇠로 펼친다. 가격, 조건, 방법, 갱신, 출처, 확인일은 펼친 안에 두고, 재확인이 필요한 항목만 빨강으로 밖에 표시한다.

**관심 주제.** 설정 내 정보 맨 위 "관심 있는 일"은 알약 칩 9개(14 / 500, `--hair-2` 테두리, 켜지면 `--ink` 테두리와 `--select-2` 바탕)이고 줄이 넘치면 다음 줄로 간다. 처음에는 수강·학적, 계절학기, 장학금, 근로·인턴장학, 졸업이 켜져 있다. 고른 주제만 목록에 나오고 나머지는 관심 밖에 접힌다.

**체크와 저장.** 체크는 "끝냈어요" 표시다. 로그인했으면 서버에 남아 다른 기기에서도 같고, 로그인 전에는 이 브라우저에만 남았다가 로그인할 때 서버로 옮긴다. 끝낸 마감은 알림 메일과 캘린더 구독에서 빠진다. 저장은 책갈피이고 서버에 남아 마감 알림 메일로 이어진다. 관심 밖의 행을 저장하면 목록으로 올라온다.

**문구.** 한 화면에 설명 문장은 한 줄을 넘기지 않는다. 규칙을 설명해야 쓸 수 있는 것은 화면을 고친다. 수치와 방법은 README와 `docs/`에 적고 학생 화면에는 두지 않는다.

## Motion

없음. 접기와 펼치기는 즉시 바뀐다. 버튼 배경 전환만 120ms이고 `prefers-reduced-motion`에서는 끈다.

## States

- 불러오는 중. 목록 자리에 `--paper-2` 면 하나.
- 오류. 머리 아래 `--alarm` 글자 한 줄과 "다시 시도".
- 비어 있음. 요약 한 줄이 "이번 주에 끝나는 일은 없어요"로 바뀌고 관심 밖이 펼쳐진다.
- 끝냈어요. 체크가 채워지고 글자가 흐려지며 취소선이 그어지고 형광펜이 사라진다. 요약 한 줄의 건수가 줄어든다.
- 포커스. 2px `--ink` 바깥선.
