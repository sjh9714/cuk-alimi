# 화면 디자인 계약

다음 세션과 새 화면은 이 문서의 값만 쓴다. 값을 바꾸면 여기부터 고친다. 2026-11-02에 PC 홈부터 다시 만들면서 적었다.

## Direction

**달력 한 장.** 학생이 알고 싶은 것은 "며칠 남았나"이므로 날짜 숫자가 화면의 구조이고, 나머지는 검정과 회색으로 물러난다. 빨강은 3일 안의 마감에만 쓴다. 카드와 그림자 없이 선 하나로 날짜를 묶어, 국내 학생 앱(에브리타임)에 익숙한 눈에도 낯설지 않으면서 Things처럼 조용하게 읽히게 한다.

## Type

서체는 Pretendard Variable 하나(`web/public/fonts/pretendard`, `web/src/app/pretendard.css`). 숫자는 전부 `font-variant-numeric: tabular-nums`.

| 역할 | 크기 / 굵기 / 자간 | 줄높이 | 쓰는 곳 |
|---|---|---|---|
| 날짜 묶음 숫자 | 34 / 800 / -1px | 1 | 홈 날짜 홈통의 일 숫자 |
| 홈 머리 | 34 / 800 / -1px | 1.15 | "가장 가까운 마감까지 n일" |
| 페이지 제목 | 24 / 700 / -0.5px | 1.3 | 홈 이외 페이지의 h1 |
| 구간 제목 | 17 / 700 / -0.3px | 1.4 | 접힌 구간 이름, 오른쪽 기둥 제목 |
| 공지 제목 | 17 / 600 / -0.2px | 1.4 | 행의 제목 링크 |
| 본문·입력 | 15 / 400 | 1.6 | 설명, 폼, 발췌 |
| 메타 | 13 / 500 | 1.5 | 종류, 대상, 요일, 남은 일수, 발 밑 |

대비(흰 바탕 기준): ink 21:1, body 9.9:1, mute 3.6:1, alarm 4.6:1, select 4.5:1. mute는 13px 굵기 500 이상에서만 글자로 쓴다. 다크 모드는 없다(`color-scheme: light`).

## Space and shape

- 간격 단위 4px. 행 안 세로 12, 행 사이 14, 날짜 묶음 사이 36, 구획 사이 56, 머리글 높이 56.
- 모서리 6px은 버튼, 입력, 저장 표시, 달력 선택 원에만. 카드·패널은 모서리를 만들지 않는다.
- 그림자 없음. 묶음과 구획은 1px `--hair` 선 하나로 나눈다.
- 머리글은 흰 바탕에 `--hair` 밑선 하나, 위에 붙어(sticky) 따라온다. 오른쪽 끝은 "로그인" 또는 "내 계정" 링크이고 이메일을 적지 않는다.
- 발 밑은 본문 폭 안에서 선 하나와 13px 글자. 서비스 설명은 여기에만 둔다.

## Layout

- 본문 최대 1120px, 좌우 여백 24. 왼쪽 정렬.
- 홈은 두 열 `minmax(0, 1fr) 280px`, 간격 48. 1023px 이하에서 한 열이 되고 달력은 숨는다. 720px 이하에서는 위 메뉴 대신 아래 탭.
- 홈 이외 글 페이지(설정, 품질, 개인정보)는 한 열 680px.

**홈(1280)의 읽는 순서.** 오늘 날짜(13 mute) → 머리 한 줄(34 ink. "오늘 마감 n건", "내일 마감 n건", "다음 마감까지 n일". 필터와 상관없이 가장 가까운 마감을 말한다) → 종류 탭(전체, 학사일정, 장학, 학사, 취업. 선택은 ink와 2px 밑선, 수는 mute) → 날짜 묶음 → 접힌 구간 → 발 밑. 오른쪽 기둥은 달력과 내 저장뿐이다. 혜택은 홈에 없다.

**날짜 묶음.** 왼쪽 72px 홈통에 일 숫자(34), 요일(13 mute), 그 아래 "n일 남음"(13/600 ink. 오늘, 내일, n일 남음). 달이 바뀌는 묶음은 위 여백을 64로 늘리고 숫자 위에 "12월"을 13/600 ink로 적는다. 오른쪽은 숫자 밑선 높이에 선 하나로 시작하고, 행 사이에는 선을 넣지 않는다. 3일 안이면 숫자와 남은 일수만 `--alarm`. 묶음 사이 40.

**행.** 두 줄이다. 저장 표시(20px, 모서리 6, 로그인했을 때만) + 제목(원문 새 창, 끝에 13px 바깥 아이콘 mute), 그 아래 메타 줄(종류, 대상·학년, 시작일·시각, "내게 맞음"은 select, 끝에 "자격 보기"와 "이후 일정 n" 접기가 mute로). 메타는 `gap: 14px`로만 띄우고 가운뎃점이나 세로줄을 넣지 않는다. 서버가 가운뎃점으로 이어 준 라벨은 화면에서 조각으로 나눈다.

**접힌 구간.** 열린 구간(꼭 챙길 일정, 내게 맞는 공지, 장학·학사 공지)의 카드는 한 줄기로 합쳐 날짜순이다(ADR 012). 날짜 확인 중, 취업·창업, 지역 장학, 특정 대상·분야 장학은 목록 아래에 글자 줄로 접혀 있고, 열면 그 자리에서 같은 날짜 묶음 형식으로 펼친다. 날짜 확인 중은 숫자 없이 행만 나온다.

**달력.** 선 없는 숫자 격자. 요일 머리는 전부 mute. 마감이 있는 날은 숫자 아래 점(ink), 오늘은 굵게, 선택한 날은 `--select` 원에 흰 숫자. 날짜를 누르면 그날 할 일이 있는 공지만 그날 묶음 하나로 모이고, 탭 줄 오른쪽에 "11월 4일 마감만 보는 중, 전체 보기"가 생긴다.

## References

- Things (culturedcode.com) 앱 화면 "Upcoming": 큰 날짜 숫자와 선으로 묶는 목록, 체크 표시 행, 한 칼럼. 날짜 묶음과 행의 구조를 가져왔다.
- Flighty (flightyapp.com) 앱 화면 "My Flights": "3h 30m until" 같은 남은 시간 표기, 상태만 색으로. 홈 머리의 "n일 남음"과 "색은 상태에만" 규칙을 가져왔다.
- 에브리타임 앱: 흰 바탕과 빨강 하나, 국내 학생에게 익숙한 밀도. 빨강 값과 친근한 톤을 가져왔다.
- 가져오지 않은 것: Things의 파란 아이콘과 둥근 체크, Flighty의 지구본과 어두운 배경, 에브리타임의 빨간 머리 띠와 게시판 구조.

## Motion

없음. 접기와 펼치기는 즉시 바뀐다. 버튼 배경 전환만 120ms이고 `prefers-reduced-motion: reduce`에서는 전부 끈다.

## States

- 불러오는 중: 날짜 묶음 자리에 `--hair` 색 가로 막대 세 묶음. 글자 없음.
- 비어 있음: "지금 남은 마감이 없어요." 한 줄(15 body). 필터 중이면 "조건에 맞는 마감이 없어요."와 "필터 지우기" 글자 버튼이 같은 줄. 머리 한 줄은 그대로 둔다.
- 오류: 머리 아래 `--alarm` 글자 한 줄과 "다시 시도" 버튼. `role="alert"`.
- 저장됨: 저장 표시가 `--select`로 채워지고 흰 체크. `aria-pressed`.
- 포커스: 2px `--select` 바깥선, 2px 띄움.
