# 구조

## 1. 수집에서 알림까지

```
학사일정 표 (calendar2024_list.do)      공지 게시판 (notice.do, 장학·학사·취창업)
        |                                       |
        |  하루 1회, 날짜 표 그대로              |  1시간마다 목록 읽기, 새 번호만 본문 요청
        v                                       v
+-------------------+                 +-------------------+      원문 HTML 그대로 보관
|  일정 수집기       |                 |   공지 수집기      | ---> [ notice_raw ]
+-------------------+                 +-------------------+
        |                                       |
        |  날짜 범위·제목·교정 태그               |  제목·날짜·분류·첨부 추출, 마감일 파싱
        v                                       v
   [ schedule ]                       +-------------------+      공지 1 -> 날짜 항목 N. 못 읽으면 항목 없음, status = NEEDS_REVIEW
   (파싱 없음, 성심만)                 |   파서            | ---> [ notice ] -> [ date_item ]
                                      +-------------------+      (이미지에만 날짜가 있으면 아래 받아 적기, 그래도 없으면 운영자가 입력)
                                                |
                                                |  매시 20분, 그림 공지만. 그림 주소마다 한 번, 하루 상한
                                                v
                                      +-------------------+      AI는 글자만 옮긴다. 날짜는 같은 파서가 뽑는다
                                      |  그림 받아 적기    | ---> [ image_transcript ] -> [ date_item ] (두 번 읽어 일치하면 공개, 어긋나면 CANDIDATE)
                                      +-------------------+
        |                                       |
        v                                       v
+------------------------------------------------------+
|   검수 화면    운영자가 틈날 때 분류·날짜 항목 확인/수정/추가  | ---> status = REVIEWED
+------------------------------------------------------+
        |
        v
+-------------------+      멱등 키 (user, kind, target, date) 로 1회만
|   아침 알림 (08:00) | ---> [ sent_notification ] ---> 이메일 (하루 한 통)
+-------------------+
```

## 2. 정확성 규칙이 걸리는 지점

```
                 출처 링크   확인일   마감/만료일
공지 (수집)        자동       자동     파싱 (실패 시 비움)
혜택 (수동)        사람       사람     사람

화면에 나오는 조건: 세 칸이 모두 채워짐
  - 마감일이 비면        -> "마감 확인 필요" 표시, 검수 큐
  - 혜택 확인일 > 90일   -> "재확인 필요" 표시, 알림 제외
틀린 날짜를 신고받으면  -> 그림 날짜는 바로 내림, 글 날짜는 운영자에게 메일 + 운영 일지
```
