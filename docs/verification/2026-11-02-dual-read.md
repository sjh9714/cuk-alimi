# 그림 두 번 읽기 시험 (2026-11-02)

자동 승인을 넣기 전에, 같은 그림을 두 번 받아 적어 날짜가 일치하면 믿어도 되는지 쟀다. 정답셋의 그림 공지 18건, 그림 24장을 앱과 같은 모델(`claude-haiku-5-5`)과 같은 문구로 다시 받아 적고, 앱의 추출 규칙으로 할 일 날짜를 뽑아 기존 받아 적기 결과와 정답을 비교했다.

| 항목 | 값 |
|---|---|
| 공지 | 18건 |
| 두 번의 날짜가 일치 | 18건 |
| 일치했고 정답과 같음 | 18건 |
| 날짜가 있는 공지 / 없는 공지 | 12건 / 6건 |
| 입력 토큰 / 출력 토큰 | 50,689 / 25,521 |
| 추정 비용 | $0.0178 (그림 1장 약 $0.00074) |

비용은 입력 100만 토큰 $0.10, 출력 100만 토큰 $0.50으로 계산한 값이고 청구 내역으로 확인하지 않았다.

**한계.** 불일치가 한 건도 없어서, 두 번 읽기가 오류를 잡아낸다는 증거는 이 시험에서 나오지 않았다. 이 18건은 규칙을 고칠 때 본 자료라 점수가 후하다. 같은 모델의 두 번 읽기는 같은 곳을 똑같이 틀릴 수 있다. 표본도 18건뿐이다.
