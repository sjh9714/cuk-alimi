# 웹 푸시 실제 수신 확인 (2026-11-06)

- 기기와 브라우저: 맥, Safari. 로컬 서버(`http://localhost:3000`, API `:8080`), VAPID 키는 `VapidKeyRun`으로 만든 로컬용.
- 절차: 설정 "마감 푸시"에서 "이 기기에서 켜기"로 구독하고(엔드포인트 `web.push.apple.com`), "시험 알림"(`POST /api/me/push/test`)을 눌렀다.
- 처음 결과: 서버가 "보내지 못했어요"를 냈다. 로그에 Apple 응답 `403 {"reason":"BadJwtToken"}`. VAPID JWT의 `sub`가 `mailto:cuk-alimi@localhost`였다. 연락처 기본값을 https 주소로 바꾸고 쓸 수 없는 연락처는 서버가 뜰 때 막게 했다(`0f35d6a`).
- 고친 뒤: 서버 응답 `{"sent":1}`, 사용자가 맥에 "CUK 알리미 시험 알림"이 뜬 것을 눈으로 확인했다.
- 확인하지 못한 것: 크롬, 안드로이드, 아이폰(홈 화면 앱, HTTPS 필요). 아침 8시 D-3·D-1 예약 발송은 테스트(`ApiFlowTest`)로만 확인했다.
